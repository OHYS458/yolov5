# YOLOv5 作业 To-Do List（详细步骤）

> 目标：完成课程作业的目标检测项目，包含训练、评估、结果展示与报告提交。

## 1. 明确作业要求与评分点

- 阅读老师给出的作业说明（主题、提交物、截止时间、展示形式）。
- 记录必须提交的材料：代码、训练日志、权重文件、结果图/视频、报告或答辩 PPT。
- 确认可自由选择的数据集与检测对象范围。

## 2. 梳理 YOLOv5 总体框架

- 跟随视频/资料梳理 YOLOv5 的核心模块：
  - 输入预处理与数据增强
  - Backbone、Neck、Head 结构
  - Loss 与 NMS 推理流程
- 画出简要流程图（训练与推理各一张）。
- 准备 5-10 句话的口头介绍或报告说明。

## 3. 选定数据集与检测对象

- 选择数据集来源：
  - 公共数据集（COCO 子集、VOC、其他公开数据）。
  - 自采集图片/视频并进行标注。
- 明确检测对象类别（1-5 类为宜，便于展示）。
- 规划数据规模（建议训练集 100-500 张起步）。

## 4. 数据准备与标注

- 收集原始图片/视频并统一分辨率与格式。
- 使用标注工具（LabelImg、CVAT 等）完成标注。
- 转换为 YOLO 格式：
  - 每张图片对应一个 .txt 标注文件。
  - 每行格式：class_id x_center y_center width height（归一化）。
- 划分数据集：train/val/test（如 8/1/1）。
- 编写 data.yaml（类别名、路径、数量）。

## 5. 环境配置与官方示例跑通

- 安装 Python 环境与依赖（参考官方 yolov5 README）。
- 下载或克隆 YOLOv5 项目。
- 运行官方示例命令（训练、验证、推理）确保无报错。
- 记录可复现的命令与版本信息。

## 6. 训练自定义数据集

- 选择模型规模（yolov5s/m/l/x）。
- 调整训练参数：
  - batch size、img size、epochs
  - 选择预训练权重或从头训练
- 启动训练并保存最优权重。
- 关注训练曲线与指标（loss、mAP）。

## 7. 评估与结果展示

- 运行验证或测试脚本得到 mAP、Precision、Recall。
- 选取代表性图片/视频进行推理。
- 生成结果可视化（带框图片、检测视频）。
- 准备 3-5 张对比图（原图 vs 预测）。

## 8. 报告与答辩材料整理

- 报告结构建议：
  - 任务简介与数据集
  - YOLOv5 原理概述
  - 训练过程与参数
  - 结果与分析
  - 总结与改进方向
- 收集关键截图（训练曲线、预测结果）。
- 整理代码结构与运行命令。

## 9. 提交前自检清单

- 代码可运行，训练/推理命令可复现。
- 权重文件完整且对应最终结果。
- 结果图/视频清晰且可展示。
- 报告或 PPT 内容齐全。
- 所有文件按要求命名并打包提交。
